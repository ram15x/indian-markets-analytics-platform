Indian Markets Analytics Platform

Past figures for 1,772 Direct Growth mutual funds, computed from AMFI NAVs and checked twice by code. Facts only: no advice, no predictions.

Try: 3 year CAGR SIP XIRR old fund name compare

Use your own model key (optional)

Without a key, a simple scripted parser reads your question; it understands fewer phrasings. With a key, your chosen model plans the question and code checks the plan. The key stays in this page's memory and is sent only to your local server for each request. It is never saved.

My Groww stock holdings (optional, read-only)

Reads your stock holdings from Groww's official API using an access token you generate in Groww Cloud. Read-only: this app has no code that can place or change orders. The token stays in this page's memory and is never saved. Value uses NSE's end-of-day closing prices once you run python prices.py (not live). Mutual funds are not included in this API; use the CAS section for those.

My mutual funds from a CAS statement (optional)

Use the DETAILED Consolidated Account Statement that CAMS or KFintech email you (a PDF, usually locked with your PAN in capitals). It is read on this computer only, in memory: not saved, not sent anywhere else. Your name, PAN, email and address are never shown or kept; folio numbers are masked. Values are as printed in the statement on its date.
